# Contribuindo

Contribuições são bem-vindas.

## Desenvolvimento

1. Faça um fork do projeto.
2. Crie uma branch para sua alteração.
3. Faça alterações pequenas e bem documentadas.
4. Execute os testes disponíveis.
5. Atualize a documentação quando necessário.
6. Envie um Pull Request.

## Padrão de commits

Exemplos:

- feat: add image upload
- fix: correct player refresh
- docs: update deployment guide
- chore: update project structure

## Segurança

Não envie para o repositório:

- senhas;
- tokens;
- arquivos `.env`;
- chaves privadas;
- bancos de dados;
- arquivos de mídia de produção.
